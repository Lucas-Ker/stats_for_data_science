## 📄 About the Project

Unlike a single analysis project, this repository functions as a **"digital garden"** and a **living portfolio** of my learning journey in statistics.

This project serves as a practical, hands-on guide to the fundamental concepts of statistics, building from foundational theory to practical application in Data Science and Machine Learning. The goal is to build a comprehensive portfolio piece that not only demonstrates technical skills in Python, but also showcases a deep understanding of the *why* behind the statistical principles that underpin data-driven decision-making.

This is a project in **continuous evolution**. It will be updated regularly with new notebooks, more advanced techniques, and refactorings, reflecting my ongoing growth and deepening in the Data Science career.

**Dataset:** The data analyzed in this project comes from the "Video Game Sales with Ratings" dataset, available on [Kaggle](https://www.kaggle.com/datasets/rush4ratio/video-game-sales-with-ratings).

---

## 📚 Topics and Applied Concepts (Index)

This repository is organized by topics. Each notebook focuses on a pillar of statistics and demonstrates its practical application.

1.  **Exploratory Data Analysis (EDA):** Learn to summarize, visualize, and understand the main characteristics of a dataset.

2.  **Data Distributions & Inference:** Build the theoretical groundwork by exploring probability, random variables, and the common distributions used to model real-world phenomena.

3.  **Experimentation & Hypothesis Testing:** Apply a scientific framework to validate assumptions and make decisions based on data.

4.  **Introduction to Machine Learning:** Use our statistical foundation to build and evaluate predictive models for regression and classification tasks.

## 🚀 How to Run the Project

1. **Clone the repository:**

```bash
git clone [https://github.com/Lucas-Ker/stats_for_data_science](https://github.com/Lucas-Ker/stats_for_data_science)
cd stats_for_data_science
```

2. **Create and activate the virtual environment:**

```bash
python3 -m venv venv
source venv/bin/activate
```

3. **Install dependencies:**

```bash
pip install -r requirements.txt
```

4. **Get the Data**

   You need the raw data files inside the `data/` folder. Follow the manual download steps:

   * **a.** Go to the dataset page on Kaggle: [Video Game Sales with Ratings](https://www.kaggle.com/datasets/rush4ratio/video-game-sales-with-ratings).
   * **b.** Click the “Download” button to get the `.zip` file (likely named `archive.zip`).
   * **c.** Unzip the file.
   * **d.** Copy the main file (e.g., `Video_Games_Sales_as_at_22_Dec_2016.csv`) into this project’s `data/` folder.

5. **Run the Jupyter notebooks:**

```bash
jupyter lab
```

* Open the `notebooks/` folder and explore the case studies.
